# Анимации младших арканов «Астрального Героя»

56 подготовленных анимаций, 14 карт каждой масти. Добавлены из авторского архива «анимация младших арканов.rar» 12 октября 2026. Эта папка дополняет существующие ассеты репозитория; корневые WebP/WebM и final_deck.json не заменены.

## Состав

- videos/ — 56 MP4 с H.264 и сохранённым звуком AAC.
- posters/ — 56 WebP-постеров.
- MINOR_ARCANA_ANIMATIONS.json — соответствия устойчивым IDs, длительность, размеры и SHA-256.
- MINOR_ANIMATIONS_NOTES.md — смысловые наблюдения и правила показа.
- index.html — галерея с относительными путями. Её можно открыть после скачивания папки/репозитория либо разместить как статическую страницу. Обычная страница файла на github.com не воспроизводит HTML как сайт.

## Показ и смысл

По умолчанию — статичная карта; видео запускается по нажатию один раз, без звука, с возможностью включить звук и повторить. После завершения возвращать обычное изображение карты. Бесконечная петля не назначена: некоторые ролики заканчиваются другой позой или крупным планом.

Утверждённый канон 1.0.0 не изменён. Анимации — отдельный визуальный слой, новые значения автоматически не назначаются. В приложении/спикерах подключение пока не выполнено.

Все 56 обработанных видео прошли проверку декодирования. Визуальная проверка — временные выборки кадров; звук не прослушивался и не транскрибировался. Исходный авторский RAR в эту папку не входит; здесь находятся облегчённые версии.
