# Младшие арканы Астрального Героя: анимационный комплект

56 роликов: четыре масти по 14 карт. Проверены имена и соответствия нашим устойчивым ID. Почти все длятся 8 секунд; Пятёрка Мечей — 15.86 секунды. Оригиналы не изменены.

## Что с ними делать

Основное применение — живое раскрытие выпавшей карты. Сначала показать обычное изображение, затем дать воспроизвести короткую сцену, после неё продолжить чтение Pilot/Margot. Не заставлять клиента ждать обязательного просмотра всех карт. В раскладе по умолчанию остаются статичные карточки; ролик открывается у выбранной карты.

В Энциклопедии — отдельная кнопка оживления рядом с картой. В дневнике — сохранять ID и версию ассета, не копировать видео в каждую запись. Для коротких публикаций можно выбирать выразительные сцены; публикации в этой задаче не создавались и не отправлялись.

## Как показывать

- Воспроизводить один раз, с возможностью повторить.
- После окончания возвращать статичную авторскую карту. Некоторые ролики заканчиваются крупным планом или другой позой.
- Звук по выбору клиента, старт без звука. В комплекте звук сохранён.
- Загружать только выбранное видео; у остальных — изображение. Рекомендация для элемента video: preload=none, controls, playsinline, без loop.
- Не назначать всем 56 бесконечную петлю: для этого требуется отдельно оценить стык последнего и первого кадров каждого ролика.

## Смысловой слой

Утверждённый канон v1.0 не изменён. Анимация визуализирует движение, но не является автоматическим основанием для новой трактовки. По ID приложение знает и видео, и основной смысл; отправлять видео модели при каждом раскладе не требуется. Если конкретное действие окажется важным для авторского значения, достаточно добавить утверждённую короткую заметку к этой карте.

Особенно показательные наблюдения:

- **Восьмерка Жезлов:** В световом движении вокруг часов усиливается организация времени. Авторский смысл остаётся: время, управление им и власть. Не переводить движение в автоматическое «всё ускоряется».
- **Восьмерка Кубков:** По выбранным кадрам фигура поднимается по лестнице. Это согласуется с утверждённым путём к себе; не добавлять уход/отказ от жизни по классическому названию.
- **Шестерка Мечей:** Фигура и структура мечей меняют положение; танец делает энергетическую сторону нагляднее. Канон остаётся управлением энергией через информацию.
- **Пятерка Мечей:** В выбранных кадрах усиливаются свет, дым/пыль и движение лепестков; павшие остаются лежать. Причину их гибели анимация не устанавливает. Боль и жажда жизни сохраняются.
- **Четверка Кубков:** Женщина меняет положение предлагаемого кубка, мужчина кратко поворачивает голову. Не объявлять по этому движение окончательным принятием предложения.
- **Паж Жезлов:** Паж бежит к зрителю, камера приближается до портрета, рамка выходит из кадра. Это последовательность действия; при постоянном повторе будет заметен скачок конца к началу.
- **Король Кубков:** Король встаёт и поднимает чашу. Это дополнительное действие относительно статичной карты; не делать из него новый канон без авторского пояснения.
- **Королева Жезлов:** Кошка меняет положение рядом с троном. Движение спутника оживляет сцену, но не требует отдельного значения.
- **Рыцарь Мечей:** Движение коня и меча усиливает напор. При чтении сохранять вопрос клиента и согласованное основное значение, не назначать обязательную внешнюю агрессию.

## Техническая подготовка

Облегчены все 56 роликов; единые английские имена по ID, отдельные WebP-постеры и manifest. H.264/MP4, 24 кадров/с, максимум 960 px по высоте без увеличения исходных 360×640, AAC 64 kbit/s, faststart. Изображение при сжатии может терять мелкие детали; исходники остаются в загруженном архиве.

Видео: **87.58 MiB → 30.26 MiB**, сокращение **65.5%**. Пятёрка Мечей отдельно: 13.45 MiB → 0.84 MiB. Это фактически полученный размер файлов, а не прогноз сетевого расхода приложения.

## Проверка и ограничения

Проверены 56 уникальных соответствий полного младшего состава, метаданные, воспроизводимое декодирование обработанных файлов, длительность и размер, наличие звука, целостность ZIP. Визуальная проверка: три выборочных момента для всех 56 и семь моментов для восьми выбранных карт. Это не полный непрерывный просмотр всех роликов. Звук не прослушан и не транскрибирован. Браузерная проверка Telegram/web пока не выполнена.
